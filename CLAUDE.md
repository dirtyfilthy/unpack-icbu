# unpack-icbu

Open source tool that converts Apple Calendar archives (`.icbu`) to `.ics`.

## Data rule

This repo is public. Never commit real calendar data, or anything derived from it: no names, email
addresses, domains, event titles, UIDs or file paths from a real archive, in code, tests, docs, commit
messages or issue text. The test archive is generated by `tests/make_fixture.py` at test time, using `example.com`/`example.org`
addresses and made-up names. Reproduce real-world bugs there with invented events.

Real archives are processed from outside this repo: pass input and output paths as arguments, and
never copy or write into this directory.

`.git/hooks/pre-commit` blocks calendar files outside `tests/fixtures/` and any staged text matching
the private denylist in `.git/info/denylist` (one extended regex per line, case-insensitive, untracked).
